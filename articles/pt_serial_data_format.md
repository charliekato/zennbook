# セイコー PT シリアルデータ仕様

## 1. パケット形式

- **1パケット = 16 byte**
- 1 byte目：`STX = 0x02`
- 16 byte目：`ETX = 0x03`
- 15 byte目でデータ種別を判定する

| 15 byte目 | データ種別 |
|---|---|
| `L` | Lap |
| `G` | Goal |
| `K` | 引継ぎ |
| `J` | リアクションタイム |
| その他 | Running Timer または Reset / Start |

---

## 2. 共通フォーマット

| Byte | 内容 |
|---:|---|
| 1 | `STX (0x02)` |
| 2 | 常に `A` |
| 3 | Running Timer：`R` / Lap・Goal：着順（未使用） |
| 4 | レーン番号（Running Timerではスペース） |
| 5 | Lap・Goal：着順 / その他は基本的に未使用 |
| 6 | データ |
| 7～14 | 時間等のデータ |
| 15 | データ種別：`L` / `G` / `K` / `J` 等 |
| 16 | `ETX (0x03)` |

---

## 3. Running Timer / Reset / Start

**3 byte目が `R` の場合、Running Timer系のデータ**と判定する。

通常のRunning Timerでは、時間が **7～13 byte目**に入る。

| Byte | 内容 |
|---:|---|
| 7 | 10分の位 |
| 8 | 1分の位 |
| 9 | `:`（1分未満ではスペース） |
| 10 | 10秒の位 |
| 11 | 1秒の位 |
| 12 | `.` |
| 13 | 1/10秒 |
| 14 | スペース |

- 1/10秒まで表示する
- 1/100秒の桁はない
- 1分未満の場合、9 byte目はスペース

### Reset / Start の判定

Running Timerの開始・リセット時には、以下の特殊なデータが送られる。

#### Reset

```text
b'\x02AR       0.00 \x03' -> Reset信号

```

#### Start

```text
b'\x02AR       0.0  \x03' -> Start信号

```

#### 通常のRunning Timer

```text
b'\x02AR    1:46.3  \x03' -> Runnint Timer

```

#### Running Timer系の判定まとめ

```text
 b'\x02AR       0.00 \x03'  -> Reset
 b'\x02AR       0.0  \x03'  -> Start
 b'\x02AR    1:46.3  \x03'  -> Running Timer
 ```

Reset は PTをReset したときにこの信号が来る。Reset後はStart信号が来るまで
信号は何も来ない。

## 4.Lap / Goal
15 byte目が**L**または**G**の場合
* 時間 7～14 byte目
* 4byte目 : レーン番号
* 5byte目 : 着順
* 3byte目 : 着順らしいが使用しない

| Byte | 内容                     |
| ---: | ---------------------- |
|    3 | 着順（未使用）                |
|    4 | レーン番号                  |
|    5 | 着順                     |
| 7～14 | タイム                    |
|   15 | `L` = Lap / `G` = Goal |

#### 例
```text
b'\x02A454  1:29.30L\x03'
```
* 4byte目 = `5` -> **5レーン**
* 5byte目 = `4` -> **4位**
* 7～14byte目　=  `1:29.30` -> **1分29秒30**
* 15byte目 = `L` -> **Lap**

## 5.リアクションタイム
15byte目が`J`の場合。
* タイム : 10～13 byte目
  - Lap / Goal / Running Timer より1byte左にずれる
  - 11 byte目: `.` (小数点)
* 4byte目 : レーン番号
* 10秒以上の表現方法は不明 (おそらく対応していない)
* マイナスのリアクションタイムはどう表現されるか不明(実験データが不足のため)
    (たぶん、想像だが 9byte目が`S`ではなく`-` になるのでは?)

#### 例
```text
b'\x02A 4  S0S0.69 J\x03' -> 4レーンのリアクションタイムが0.69秒
```

## 6.引継ぎ
15byte目が`K`の場合。
* 4byte目 : レーン番号
* 9byte目 : `+` か `-`
* タイム : 10～13 byte目
  - Lap / Goal / Running Timer より1byte左にずれる
  - 11 byte目: `.` (小数点)
* その他の値は基本的に使用しない
## 例
```text
b'\x02A0502 0+0.63 K\x03'  -> 5レーンの引継ぎが 0.63秒
b'\x02A0202 0+0.51 K\x03'  -> 2レーンの引継ぎが 0.51秒
b'\x02A0402 0+0.54 K\x03'  -> 4レーンの引継ぎが 0.54秒
```
リレー以外の時もターン時にlapの信号のしばらく後で引継ぎの信号が来る。その場合は常に-0.00秒
